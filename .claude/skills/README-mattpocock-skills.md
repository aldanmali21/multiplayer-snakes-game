# Matt Pocock's skills (vendored)

The skill folders here are copied from [mattpocock/skills](https://github.com/mattpocock/skills)
at commit `abeeaf95660ba9e8b7c753eb38f441ca707a8823` (plugin version 1.3.2), MIT licensed
(see `LICENSE-mattpocock-skills`).

Only the 27 skills that ship in the official Claude Code plugin are included. The upstream
`in-progress`, `deprecated` and `misc` folders and the Codex-only `agents/openai.yaml`
files were left out.

To update, re-copy the folders from a newer upstream commit. Alternatively, uninstall these
and use the self-updating plugin: `claude plugin install mattpocock-skills@claude-plugins-official`
(don't use both, or every skill appears twice).

Start with `/setup-matt-pocock-skills` once per repo, then `/grill-with-docs` before a change.
